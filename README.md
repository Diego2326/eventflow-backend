# EventFlow Backend

Backend de EventFlow construido con Spring Boot y Gradle.

## Requisitos

- Java 21
- Gradle (o usar `./gradlew`)

## Ejecución local

```bash
./gradlew bootRun
```

## Tests

```bash
./gradlew test
```
